MEU TREINO — INSTALAÇÃO PWA

1. Extraia todos os arquivos do ZIP.
2. Publique o conteúdo desta pasta na raiz de um repositório GitHub Pages (ou outra hospedagem HTTPS).
3. Abra o endereço HTTPS no Chrome do Android.
4. Menu ⋮ > Adicionar à tela inicial > Instalar, quando disponível.
5. Abra uma vez conectado à internet para instalar o cache offline.

IMPORTANTE: abrir index.html diretamente como arquivo local NÃO instala o PWA.
Os dados são guardados localmente por origem/domínio. Se você usava o HTML local, exporte os registros anteriores e faça a migração manual quando possível. A importação JSON funciona com backups criados nesta versão; o CSV anterior não restaura o estado completo.
Faça backups JSON regulares. Não apague dados do navegador sem backup.
